Python Quiz Application

1. Project Overview

The Python Quiz Application is a simple database-based project developed using Python and SQLite. It allows users to attempt multiple-choice questions and view their final scores.

2. Objectives

- To develop an interactive quiz application.
- To understand Python programming concepts.
- To connect Python with an SQLite database.
- To store quiz questions and user results.
- To calculate scores and percentages.

3. Technologies Used

- Programming Language: Python 3
- Database: SQLite
- Module: sqlite3
- Date and Time: datetime

4. Main Features

- User name input.
- Multiple-choice questions (MCQs).
- Automatic answer checking.
- Score calculation.
- Percentage calculation.
- Saving quiz results in the database.
- Input validation.

5. Database Tables

Questions Table
Stores questions, four options, and their correct answers.

Results Table
Stores player name, score, total questions, and attempt date and time.

6. How to Run

1. Install Python 3.
2. Save the source code as "quiz_app.py".
3. Run the program.
4. Enter your name.
5. Answer the questions using A, B, C, or D.
6. View your final score.

7. Project Files

- "quiz_app.py" – Main Python source code.
- "quiz_app.db" – SQLite database (created automatically when the program runs).
- "README.md" – Project documentation.

8. Conclusion

This project demonstrates the practical implementation of Python programming and database connectivity using SQLite. It helps users understand how data can be stored, retrieved, and managed through a simple quiz application.
